# Site SEO pass (web/)

## What
Audited `web/` head tags, JSON-LD, sitemap and hreflang. Added Twitter card tags
(title, description, image, image alt), `robots` with `max-image-preview:large`,
a `WebPage` JSON-LD node per page (language, `dateModified`), `x-default` in the
sitemap pairs, and a per-language social image alt (the Arabic pages carried the
English one). `web/tests/site.test.mjs` pins each.

## Mistakes
No wrong turn. Found late: the Arabic home page's `og:image:alt` was English text
on a `lang="ar"` page, which the old tests could not see.

## What worked
Reading `web/build.mjs` and the tests before editing: titles, descriptions, canonical,
hreflang reciprocity, FAQPage, image sizes and alt were already enforced, so the work
was the gaps only. Copy was left alone: every claim there already came from README.md.

## Rules
- A new head tag gets a test that reads the built HTML, not the source.
- Per-language strings live in `ui` in `web/pages.mjs`, never inline in `build.mjs`.
- Left as is: no `robots.txt` (a project page cannot serve one), no Arabic twins for the
  guide pages (the 2026-10-31 docs-and-site entry: no twin, no `alternate`).
