## Highlights

- **Links are clickable with a plain click.** A URL, a file path or a program's hyperlink (OSC 8) is underlined and drawn in your theme's blue as soon as the pointer is over it, with the hand pointer. A left click opens it. Ctrl is no longer needed.
- **Ctrl+click opens a link every time.** Before, letting go of Ctrl a moment before the mouse button dropped the click, so Ctrl+click often did nothing.

## Links

- Hovering a link marks it with an underline and the theme's link blue. If that blue is hard to read on the background, Najm picks the next blue or cyan that reads, or keeps the text colour and shows only the underline.
- Dragging across a link selects it and does not open it, so you can still copy a URL. Ctrl+click opens a link even when text is selected.
- `http`, `https` and `mailto` links open at once. Other schemes Najm supports (`ftp`, `ssh`, `git` and the rest) still ask first, and file paths still go through the same checks as before.
- Links you define yourself with `link = <regex>` keep needing Ctrl, as before.

Known limits:

- Double-clicking a URL to select it opens the link on the first click.
- In apps that use the mouse (vim, tmux with the mouse on), clicks go to the app. Hold Shift to reach links there, as before.
