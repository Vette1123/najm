## Highlights

- **See the size while you resize.** Dragging a window edge or a split divider now shows the pane's size in columns and rows (for example `120 × 30`) in a small label inside the pane. It hides after 750 ms (`resize-overlay-duration`). `resize-overlay = never` turns it off, `always` also shows it while a window opens, and `resize-overlay-position` moves it.
- **Know where a link goes before you click.** Hovering a link shows its address in a label at the pane's bottom-left corner, as a browser does. Long addresses are cut short with "…", and characters that could disguise an address (control characters, bidi controls, zero-width marks) show as `�`. Turn it off with `link-previews = false`.
- **Background blur.** With `background-opacity` below 1 and `background-blur` on, Windows 11 22H2 or later shows its acrylic material behind the window. It can be switched on in Settings now. Earlier Windows builds log a warning and show the background unblurred, as before.

## Details

- Background blur needs every pane on the OpenGL renderer. A window with a Direct3D 11 pane fades as a whole, unblurred. High Contrast shows every window opaque. Blur intensities are ignored, because Windows has a single acrylic.
- The size label and the link label are exposed to screen readers as tooltips (not yet checked with a screen reader).
- From Noctty: sturdier release and update checks (malformed tags and update journals are rejected, a draft is bound to its own create attempt), and a CI record of which tests ran, which fails a later run that silently drops one.
