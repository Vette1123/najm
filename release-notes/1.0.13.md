## Highlights

- **Settings shows changes in your open terminals before you save.** Change the font, font size, terminal theme, text colour, cursor style or padding and every open terminal shows it within a moment. **Save** keeps it; **Discard changes** or closing Settings puts everything back. Window theme, accent and opacity still preview in the window itself, as before.
- **Drag a tab out of the strip into its own window**, or drop it on another Najm window's tab strip to move it there. Dragging out of a maximized window lands the new window under the pointer. When a tab cannot move, Najm says why. Esc cancels a drag.
- **Resize split panes by dragging the divider** between them, with the mouse in a band beside it.

## Settings

- Terminal looks (font, font size, theme, text colour, cursor style, padding and padding balance) preview live in open terminals, 150 ms after you stop typing. The status line reads "Previewing now. Save to keep it, or Discard changes to undo it."
- The preview follows a config reload: if a file changes on disk while Settings is open, your unsaved drafts are shown again over the reloaded config.
- If a save fails, the preview comes back so you can see what you were about to save.
- A status message that said "noctty" now says "Najm".

Known limits:

- A tab or split you open while a change is unsaved starts with the saved settings until you save.
- The font family and theme text boxes preview when you leave the box or pick from the list, not on every keystroke.
- While the command palette previews a theme, it covers the Settings preview; your next Settings edit shows it again.

## Tabs and panes

- Tear a tab off into a new window, or drop it into another window's tab strip.
- A torn-off tab from a maximized window lands under the pointer; a tab move that fails says so instead of doing nothing.
- Drag the divider between split panes to resize them. Divider dragging got follow-up fixes for keys pressed and global hotkeys during a drag.
- Clicking a tab's close X closes the tab only if the press started on that same X.

## Command palette

- New `command-palette-hint = false` hides the palette's hint line and the row it takes, so results start right under the search box. A message the palette needs to show still brings the row back.

## Keyboard

- A key binding that chains several actions now stops at the action that closes its tab or window, instead of running the rest against whatever took its place.

## Updates and packaging

- The pre-1.0 `ghostty-vt.dll` library is no longer shipped. A small signed placeholder with the same name stays in the portable ZIP so older portable copies can still update.

## Under the hood
