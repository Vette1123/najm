Install it

  1. Run {{setupFile}}.
  2. Windows shows "Windows protected your PC" the first time. Click More info, then Run anyway.
  3. Open Najm from the Start menu.

Prefer no installer? Unzip {{portableFile}} anywhere and run najm.exe.

Why SmartScreen warns

Najm signs its builds with its own certificate, which Windows does not know yet. The warning means Windows does not recognize the publisher. It does not mean a problem was found in the file. If you want to be sure, check the file first.

Check the download

Hash the file and compare the result with its line in SHA256SUMS-windows-x64.txt:

Get-FileHash .\{{setupFile}} -Algorithm SHA256

The installer and every program file in it are signed by CN=Najm Code Signing, thumbprint 26D9DB30682A45008C05E08729B7CC9016D492FB. The in-app updater refuses anything signed by another key.

Stay up to date

Najm updates itself from its GitHub releases, and each update is signed and checksum-verified. You can turn the update check off. See how to build from source if you prefer that.
