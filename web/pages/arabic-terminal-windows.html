An Arabic terminal for Windows

Terminals are built on a grid of equal cells, which suits Latin text and breaks Arabic: letters split apart and the order runs backwards. Najm lays out right-to-left text and shapes Arabic so the letters join.

Set it up in three steps

  1. Install the current Cascadia Code release. The copy that ships with Windows has no Arabic.
  2. Add this line to %LOCALAPPDATA%\najm\config.ghostty:
font-codepoint-map = U+0600-U+06FF,U+0750-U+077F,U+08A0-U+08FF,U+FB50-U+FDFF,U+FE70-U+FEFF=Cascadia Code NF
  1. Press Ctrl+Shift+, to reload the config.

Why the font line matters

The default terminal fonts have no Arabic, so Windows draws it in Segoe UI. That font is proportional, so it sits unevenly in the grid. The line above sends every Arabic block to a monospace font that has them, and the text lines up.

To see which font each letter comes from, run:

najm +show-face --string="مرحبا"
