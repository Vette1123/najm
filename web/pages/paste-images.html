Paste screenshots into Claude Code on Windows

AI coding tools running in a terminal read screenshots straight from your clipboard, but only if the terminal tells them a paste happened. In Najm, one line makes Ctrl+V do that.

Add one line to your config

Open %LOCALAPPDATA%\najm\config.ghostty, add this line, and press Ctrl+Shift+, to reload:

keybind = performable:ctrl+v=paste_from_clipboard

performable means Ctrl+V reaches your shell as usual whenever there is nothing to paste.

What Ctrl+V does then

On the clipboardWhat the app receives
TextThe text, as a bracketed paste
Files copied in ExplorerTheir paths, quoted, separated by spaces
An imageAn empty bracketed paste, so the app reads the image from the clipboard itself

That empty paste is the same signal Windows Terminal sends, which is why tools like Claude Code and opencode can attach the screenshot.

Try it

  1. Press Win+Shift+S and capture part of the screen.
  2. Start your tool in a Najm tab.
  3. Press Ctrl+V.
