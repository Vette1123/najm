A Windows Terminal alternative you can try beside it

Windows Terminal is a good default, and it ships with Windows 11. Najm is for people who want Ghostty's core and a plain text config on Windows. The two install side by side, so trying Najm costs you nothing.

Where they differ

 NajmWindows Terminal
Terminal coreGhostty'sMicrosoft's own
ConfigurationPlain key/value file, also a Settings windowJSON file and a Settings UI
PublisherIndependent project, self-signedMicrosoft, trusted by Windows

If you need a publisher Windows already trusts, stay with Windows Terminal. Najm's self-signed certificate means SmartScreen warns you on first install.

Translate your settings

Najm does not import settings.json and never reads it. Copy the lines you use into %LOCALAPPDATA%\najm\config.ghostty:

Make it feel familiar

Windows Terminal pastes with Ctrl+V. This line does the same in Najm, including copied files and images:

keybind = performable:ctrl+v=paste_from_clipboard
