Ghostty for Windows: what you can install today

At the time of writing, the Ghostty project ships for macOS and Linux and has no official Windows release. If you want Ghostty's terminal core on Windows now, a community build is the way to get it. Najm is one of those builds.

What Najm is

Najm is a native Win32 terminal that uses Ghostty's terminal core. Its Windows app comes from Noctty, which brought Ghostty to Windows, and Najm follows Noctty closely while shipping its own fixes on top.

Ghostty (terminal core, macOS and Linux)
  └── Noctty (Ghostty's core in a native Windows app)
        └── Najm (Noctty plus its own fixes and releases)

Najm is not affiliated with the Ghostty or Noctty projects. All three are MIT licensed.

What carries over from Ghostty

  • The same config syntax, read from %LOCALAPPDATA%\najm\config.ghostty.
  • Most options, and hundreds of bundled themes. List them with najm +list-themes.
  • The Kitty graphics and keyboard protocols.
  • Shell integration: prompt marks, and jumping to the previous or next command.

What Windows adds

  • A real installer, plus a portable ZIP, with signed updates inside the app.
  • Automatic discovery of PowerShell, cmd, Git Bash and WSL distros.
  • An "Open Najm here" entry in Explorer, jump lists and toasts.
  • A Direct3D 11 renderer (beta) for machines without OpenGL 4.3, such as Remote Desktop sessions and VMs without 3D acceleration.

Move your config

Open the config file, then paste in the Ghostty lines you use:

notepad "$env:LOCALAPPDATA\najm\config.ghostty"

Press Ctrl+Shift+, to reload. To see every option, run najm +show-config --default --docs. The installer does not add najm to PATH, so run this from the install folder or add that folder to PATH.
